Zásady ochrany osobních údajů

Poslední aktualizace: 4. 8. 2026

Tato aplikace (VG MEDIA API NEW, App ID 1673360010603671) je interní nástroj agentury VG Media (Martin Gottvald), který slouží ke správě reklamních kampaní klientů na platformě Meta (Facebook, Instagram) prostřednictvím Meta Marketing API.

Jaká data zpracováváme

V rámci provozu aplikace přistupujeme k datům z Meta Business/Marketing API, ke kterým nám klienti udělili přístup v rámci správy jejich reklamních účtů. Jde zejména o:

  • údaje o reklamních účtech, kampaních, sadách reklam a reklamách,
  • výkonnostní a reportingové metriky (zobrazení, prokliky, útrata, konverze apod.),
  • údaje o produktových katalozích (u dynamických/katalogových kampaní),
  • identifikátory stránek a Instagram účtů propojených s reklamními účty.

Aplikace nezpracovává osobní údaje koncových zákazníků klientů nad rámec agregovaných reklamních dat poskytovaných Meta Marketing API.

Účel zpracování

Data používáme výhradně za účelem:

  • analýzy a optimalizace výkonu reklamních kampaní klientů,
  • vytváření a správy reklamních kampaní na základě schválení klienta,
  • reportingu výsledků klientům.

Sdílení dat

Data nesdílíme s třetími stranami nad rámec nezbytný pro poskytování agenturních služeb (samotná platforma Meta). Data neprodáváme.

Zabezpečení

Přístupové tokeny a API přístupy jsou uchovávány zabezpečeně a nejsou veřejně přístupné. Přístup k datům mají pouze pověření pracovníci agentury VG Media.

Uchovávání dat

Data uchováváme po dobu trvání spolupráce s klientem a po dobu nezbytnou pro plnění smluvních a zákonných povinností.

Práva subjektů údajů
